# SkyPilot Simulator

## Descrição
Sistema de simulador de carreira de piloto.

## Tecnologias
- Java 21
- Spring Boot 3.3.3
- Maven
- Angular
- PostgreSQL
- Docker
- Ollama

## Estrutura
- backend
- frontend

## Como executar
1. Backend:
   cd backend
   mvn spring-boot:run

2. Frontend:
   cd frontend
   npm install
   ng serve
